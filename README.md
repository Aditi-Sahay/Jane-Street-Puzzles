# Jane Street Puzzles — Solutions

This repository contains my personal solutions to the [Jane Street Monthly Puzzles](https://puzzles.janestreet.com/). Each puzzle is approached through logical reasoning, mathematical problem-solving and Python programming wherever applicable. Solutions are organised by month for clarity and consistency.

## Repository Structure

The repository is organised into year-wise and month-wise folders (e.g. `2026/11-pressure-points/`).

Each monthly folder typically includes:

| File | Description |
|---|---|
| `README.md` | Overview of the puzzle, initial approach and reasoning |
| `achievement.md` | Evidence of leaderboard recognition, where applicable |
| `solution.md` | Structured, step-by-step explanation of the solution |
| `solver.py` | Python code developed to automate, validate or explore parts of the solution, wherever applicable |
| `notes.md` | Additional thought processes, diagrams and observations (optional) |

## About the Puzzles

[Jane Street](https://www.janestreet.com/) publishes monthly logic, mathematics and programming challenges through its [puzzle platform](https://puzzles.janestreet.com/).

The puzzles range from relatively straightforward to highly complex and often involve a combination of:

- Combinatorics
- Graph Theory
- Probability
- Optimisation
- Algorithm Design
- Logical Reasoning

Working through these challenges provides an opportunity to develop problem-solving skills, mathematical intuition and computational thinking.
